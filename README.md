# Voice Notes releases

Signed and notarized builds of Voice Notes for Macs with Apple silicon (M1 or later, macOS 14+).
This repository holds only the finished app; the source code is private.

## Install

1. Download the `.dmg` from the [latest release](../../releases/latest).
2. Open it and drag **Voice Notes** into **Applications**.
3. Open Voice Notes from Applications. A setup screen walks you through the rest.

Installed copies update themselves from this page.
